# ADSolutions Previews

Shared deployment repository for private website concepts generated by the ADSolutions Website Factory.

## Rules

- One folder per preview slug.
- Preview pages must include `noindex,nofollow,noarchive`.
- The root page never lists active prospect previews.
- Generated previews are deployment artifacts; reusable Factory source remains in `ADSolutionsCRM/adsolutions-website-factory`.
- Current first live case: `genius-cleaning/`.

## Intended URL pattern

```text
https://adsolutionscrm.github.io/adsolutions-previews/<client-slug>/
```

A custom preview domain can be attached later without changing client slugs.
